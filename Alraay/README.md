# تحديث جزارة الراعي — نسخة الموقع (بدون تطبيق)

هذا التحديث خاص بنسخة الموقع فقط (اللي على GitHub Pages بدون PWA) — منفصل تمامًا عن لوحة تحكم نسخة التطبيق اللي فيها توكن قديم.

## اللي اتعمل

### 1. إصلاح مشكلة فتح الصفحة من نص/آخر الصفحة
- زودنا مدة تثبيت الـ scroll لأعلى الصفحة من 400ms لـ 700ms بعد فتح أي ركن
- ضفنا معالجة لحالة رجوع المتصفح من الذاكرة المؤقتة (bfcache) اللي ممكن تعيد وضع السكرول القديم
- ضفنا `overflow-anchor: none` عشان نمنع المتصفح من "تثبيت" مكان غير متوقع في الصفحة لما المحتوى بيتحمل بشكل غير متزامن (زي تحميل data.json دلوقتي)

### 2. لوحة تحكم جديدة (admin.html)
- كل الأسعار والأصناف والأركان + معلومات المحل (نص "عننا"، العنوان، أرقام التليفونات، رقم الواتساب، نص الحقوق) بقت في ملف منفصل `data.json`
- `script.js` بقى يحمّل البيانات دي وقت فتح الصفحة بدل ما تكون مكتوبة جوه الكود مباشرة
- `admin.html` بيتكلم مع GitHub API مباشرة من المتصفح (بدون أي سيرفر) — بنفس الطريقة اللي اتعملت واتأكد إنها شغالة في نسخة التطبيق

**ملحوظة مهمة:** التوكن اللي عندك حاليًا اتعمل لنسخة التطبيق (PWA). لازم تعمل توكن **تاني منفصل** لنسخة الموقع دي، وتحدد صلاحياته على نفس الريبو (أو الريبو المختلف لو الموقع في مكان تاني).

## قبل الاستخدام
افتح `admin.html` وعدّل أول 4 قيم بحسب مكان الموقع الحقيقي عندك:
```js
const GITHUB_OWNER  = 'MyDigital-ID';
const GITHUB_REPO   = 'MyDigital-ID.github.io';
const GITHUB_BRANCH = 'main';
const GITHUB_PATH   = 'Alraay/data.json';
```
(القيم دي حاليًا تخمين بناءً على الرابط المباشر اللي أرسلته قبل كده: `mydigital-id.github.io/Test-rep/Alraay-order/` — يُرجى التأكد إذا كان مسار المشروع الفعلي مختلف)

## خطوات الرفع
1. ارفع الملفات دي فوق الموجودة حاليًا: `index.html`, `style.css`, `script.js`, `data.json` (ملف جديد), `admin.html` (ملف جديد)
2. اعمل GitHub Token جديد (Fine-grained، على الريبو ده بس، صلاحية Contents: Read and write)
3. افتح `admin.html`، الصق التوكن، وجرّب تعديل أي سعر واحفظ

## لسه محتاج تتأكد منه
- المسار الصحيح لـ GITHUB_PATH في admin.html (حسب مكان الموقع الفعلي)
- تجربة فتح كل ركن للتأكد إن مشكلة السكرول اتحلت خالص على جهازك
