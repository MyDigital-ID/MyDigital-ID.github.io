# 🛒 سوبر ماركت PWA

تطبيق ويب تقدمي لتوصيل طلبات السوبر ماركت للمنازل.

## 📁 هيكل الملفات

- `index.html` — الواجهة الرئيسية
- `style.css` — التنسيقات والأنيميشن
- `script.js` — الوظائف والتفاعل
- `data.json` — بيانات المنتجات
- `manifest.json` — بيانات التطبيق (PWA)
- `service-worker.js` — العمل بدون إنترنت
- `admin.html` — لوحة التحكم (لاحقاً)
- `assets/` — الصور والأيقونات
